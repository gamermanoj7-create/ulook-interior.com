ULOOK INTERIOR — V3 REPAIR REPORT
Date: 13 November 2026

IMPLEMENTED CHANGES
1. Removed the full-screen ULOOK logo intro overlay, its skip button, canvas/particle animation, intro CSS, scroll lock and all intro-only code. The website opens directly to the homepage; the branded navbar remains.
2. Fixed a root-cause hero animation bug: the exterior-to-interior controller previously ran before the homepage DOM existed and exited. It is now loaded after the page markup. Its inline style updates can override legacy !important rules, and the mobile scroll distance is shorter.
3. Rebuilt the first viewport using the approved navy / sky-blue / sage / champagne palette. The exterior photo is visible on first paint, fills its frame with object-fit: cover, and has a fallback image.
4. Reduced excessively long scroll travel in the domestic, kitchen, architecture and commercial photo galleries, plus selected scroll-led design chapters.
5. Enabled native controls on all scroll-driven cinematic videos. If autoplay is rejected, a visible tap-to-play action appears. If a media source errors, a retry action is shown. Existing muted inline autoplay remains the first attempt.
6. Corrected robots.txt and sitemap.xml to use the same Firebase canonical URL used by the site.
7. Preserved the Firebase project configuration, existing Firestore configuration and all original media files. Original backup HTML remains in source-archive.

DEPLOY FROM TERMUX
1. Download ulook-interior-v3-fixed.zip to Android Downloads.
2. Run:
   mkdir -p ~/ulook-v3-deploy
   unzip -q /storage/emulated/0/Download/ulook-interior-v3-fixed.zip -d ~/ulook-v3-deploy
   cd ~/ulook-v3-deploy/ulook-deploy-verified
   firebase deploy --only hosting
3. Confirm Firebase prints Deploy complete and Hosting URL https://ulook-interior.web.app
