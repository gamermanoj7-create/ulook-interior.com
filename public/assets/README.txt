ULOOK Interior – Footer Social Icons
=====================================
Optimized transparent WebP assets from the images supplied in this chat.

Files:
- social-google.webp
- social-facebook.webp
- social-instagram.webp
- social-youtube.webp

All images are 512 x 512 pixels. Facebook and YouTube supplied images
had a checkerboard background baked into the picture; that background
was removed and edge anti-aliasing applied. Google and Instagram
transparency was preserved.

Place these files in: public/assets/
Use object-fit: contain; set the actual displayed size in CSS.
